# 回春堂涼茶 · 陳伯 AI

> 一個用粵語演出的涼茶舖問診 demo：虛構角色扮演 + 藥材知識庫（RAG）+ 安全護欄 + 可選的真實 LLM 接入。
> 目的是示範「有護欄的 AI」同「冇護欄的 AI」有幾大分別——唔係醫療產品。

![舞台](docs/assets/demo-stage.png)

## 這是什麼

- **角色**：陳伯，回春堂第三代掌櫃（虛構角色，由 AI 扮演，已明確披露）
- **互動**：四輪問診（體質 → 時長 → 用藥 → 誰喝）→ 出涼茶方 → 自動播「煮茶」演出
- **知識**：36 味藥材、17 個症狀、多款涼茶方，全部本地 JSON / JS 資料
- **護欄**：重症轉介、用藥衝突、孕期禁忌、雙 agent 藥師覆核
- **可選**：接入任何 OpenAI 兼容模型，對白由模型生成；不接也能完整演示（內建模板引擎）

## 功能亮點

| 模組 | 說明 |
| --- | --- |
| 問診槽位 | 4 輪追問，每輪給 3–4 個可點選項，第 4 輪後強制開方 |
| 涼茶方 | 茶名、成分、功效、對症、適合體質、禁忌、性味、飲法 |
| 藥師覆核 | 第二位 agent 檢查「性味 × 體質 × 用藥 × 孕產」衝突 |
| 煮茶演出 | 拉百子櫃 → 落藥 → 開火 → 斟茶 → 出方子，純 SVG/CSS |
| 對話氣泡 | 長回覆可展開/收起，流式輸出也保留全文 |
| 舞台 | 手繪立繪、呼吸/點頭/搖頭/歪頭、雨天/寒冷濾鏡 |
| 記錄 | 對話存檔、匯出 Markdown、並排評測（開/關護欄） |

## 快速開始

```bash
# 開發（多文件，瀏覽器直接讀 src/）
python3 scripts/dev.py        # http://127.0.0.1:8787

# 出單文件（可離線雙擊）
python3 scripts/build.py      # → dist/index.html

# 資料校驗
python3 tests/test_data.py
```

> 冇 Node 都可以跑，全部用 Python 標準庫。

## 目錄結構

```
chen-bo/
├── index.html                # 開發入口（引用 src/）
├── src/
│   ├── styles/               # 11 個 CSS 分層（tokens → header → … → responsive）
│   └── scripts/              # 4 個腳本（data → engine → app → scene）
├── public/art/               # 立繪、頭像（WebP，帶透明通道）
├── data/                     # 藥材、症狀 JSON（可供外部調用）
├── docs/                     # 架構、安全、API、設計、變更
├── scripts/                  # dev / build
├── tests/                    # 資料校驗
└── dist/                     # 構建產物（gitignore）
```

## 安全與邊界

- 陳伯是**虛構角色**，由 AI 扮演，會在首次對話、頁面頂欄、每份方子上披露
- 不出診斷、不替代醫生；重症（高燒、呼吸困難、咳血、體重驟降等）一律轉介
- 用藥衝突（薄血藥、降壓藥、降糖藥、利尿藥、類固醇）會攔截並提示
- 孕婦、小兒、長期病患會縮窄建議範圍

詳見 [docs/safety.md](docs/safety.md)。
